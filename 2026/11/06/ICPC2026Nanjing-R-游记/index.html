ICPC2026Nanjing R 游记

2026/11/6 游记

省流：爆炸了，打铁。

Day -1

出发前往南京，绝赞 18h 火车乘坐中。

笔者的学校距离南京站太远了，想要完整参赛只能提前出发（）

至于为何不坐飞机，自然是没钱坐不起（

没报销太致命了。

在火车上只能耍起了，根本没心思去看书。

Day 0

昨天晚上火车热死人了，睡得不是很好。

下午去到赛场比较晚，导致基本没领到什么物料，只领到了选手固定物资，袋鼠好评。

我去，真有舞萌？可惜我和我的队友们都不会打，于是集合全队一共三十个币，打算抓娃娃。

结果是全部打水漂，没能给群友多赢回来几个。

热身赛，全是袋鼠题。

迅速切了一题，然后开始坐牢，最后爆炸，QAQ。

气死我了。

晚上和一些在南京的同学聚餐，然后去打了桌球，结果是被零封了。

希望第二天能打出状态来。

Day 1

刚开题过了好一会没人切题，感觉有点不妙，过了几分钟 CF皇帝开了 C，又过会开了 K，刚好 verlan 开了 K，花了点时间切了，闯入银牌区。

谁能想到接下来几个小时全在坐牢。

我看了看 D，感觉像是一个比较难写的 dp，sakana 和 verlan 去看 C 了，说 C 有思路，我就在旁边继续研究 D。

verlan 写完之后发现挂了，我稍微看了下代码发现写成一堆了。

不过还好，勉强能看勉强能写，但他们表示要考虑一下，我就先上去验证一下 D 的想法。

写到一半他俩在吵是不是中心对称，由于我对 D 没啥信心，加上写的时候发现我似乎漏读了一句话，比较难绷，我就边写边听了听他们的想法，脑内模拟了一下，我判断中心对称是对的，然后开始帮 verlan 改代码。

还算好改，但是不知道为什么挂了，于是决定重构。

重构之后代码变得很简洁了，但还是挂了。

此时他们说 F 能写了，我就让了出来。

然后就是 C 对着搞到了比赛结束，直接裂开。

中间 C 有一两个错误做法，但很顺畅的引导我们发现了做法。

和 sakana 讨论了一下 C 的做法，发现只要不是在四个角上就是错的，那么代码就会很简单了，怪不得是签到，剩下的事情就好办了。

等 verlan 写完 F 的代码，锅了，于是给他打印代码下去调。

写完之后轻松通过样例，冲动 submit 了一发，挂了。

再交给 verlan 写，和 sakana 讨论到一半我突然发现对角似乎不需要相等也是对的，那么就更简单了。

极速写完，发现 WA 了，此时罚时对我们来说已经不是什么事了，切题才是。

由于一直没过，我开始怀疑自己的做法是否正确，结果酿成大错。

接下来的时间就是我不断去找例子，企图 hack 我的做法，结果全都失败，搞得我很矛盾，一方面我的做法是推出来的，不可能错，我写了很多样例都支持了这点；另一方面却是总提交不过，让我不得不怀疑我自己是否是漏掉了什么边界条件。

但总找找不出来，verlan 的 F 也没调出来，sakana 没有帮他重构，此时我已经破大防了。

但我姑且还算是 leader，我得镇定下来，至少不能太失态，虽然我的队员们似乎已经绷不住了。

我很想压力 verlan 和 sakana，让他俩重构一下 F 或许还有救，但是我还是稍微收敛了一点，没有强制让他们重构，只是反复给出重构的建议，因为我也在想，没准他们就把所有的错找出来了呢？万一我压力了他们，F 就功亏一篑了呢？我手头上也压着 C 没过。

所以就开始压力自己，尝试心理暗示自己奇迹是会发生的，只要我能及时写完 C，三个人一起来看 F 或许就能过了，最后或许就能切掉三题，至少能拿下 Cu 了。

其实这个时候我的心理防线或许已经崩溃了，脑袋有点难受，有点心力交瘁了。

我让 sakana 去辅助 verlan 写 F，让他暂时不要考虑 C 的问题，有一说一，这时候应该已经有点自暴自弃了。

结果就是我一直找 hack 没找到，verlan 一直找 bug 没找到，最后梦碎铁牌了。

心累。

赛前还说应该能肘击主校区队伍，赛后直接成小丑了，真坠机了，我以后再也不在赛前发自己的牢大图了。

我刚好有个学长也在南京站，他来了我们交流了一下，发现我 C 的做法没错，但是不知道为什么挂了，这时我的大肥鱼把答案跑出来了，我一看，做法一样又不一样，再一看，tmd 题意理解错了。

三个人全都理解错题意了。

眩晕瘫坐了。

我无法接受自己以这种方式挂题，当场二次破防。OI 时期都没理解错题意过。

我们三个人以为同一个格子的沙堆是叠高高，结果 nmd 是一个格子里放多个沙堆，没招了。

两种理解的做法一样，但是答案会略有不同，最终就死在这了。

说到底还是不够自信吧，怀疑自己的做法都没去怀疑题面是否有歧义。

样例也无法体现一个格子里放多个沙堆的影响，我甚至没有去怀疑题面可能有歧义这一问题，毕竟当初我还多读了一遍英文题面，确定了一下题意，没想到还是错的。

唉，如果多看几遍题面或许我们发现一个点能提出问题，没准能得到 clarification，但我们没有，结果就是吊死在一棵树上。

累了，这个赛季第一站就爆炸，唉。

后面还有一堆事等着我去做，省赛，各科的作业 ddl 和期中期末，接着就是上海站。

没招了。
