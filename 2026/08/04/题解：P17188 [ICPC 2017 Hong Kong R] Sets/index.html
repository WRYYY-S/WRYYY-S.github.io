题解：P17188 ICPC 2017 Hong Kong R Sets

2026/8/4 题解

本题的思路并不难，具备高中知识即可通关。

但是本题的难点在于如何处理超大的读入。

但人是要会变通的，所以在赛场上我们队采用了 python 来解决这个问题。

思路

最开始的想法是矩阵快速幂，我们队的 Saka_Noa 看到的时候也是如此想的。

再手玩几个例子发现当 n≥4n\ge4n≥4 时矩阵大小会变，故放弃该思路。

后面回到这题，继续手搓这题的样例，注意到每个 sis_isi​ 中的元素都是连续的，并且注意到左右边界是可以递推的。

下面给出证明：（其实我认为还算显然）

首先假定 sis_isi​ 是个连续的整数集合，令最小的元素为 lil_ili​，最大的元素为 rir_iri​。

那么对于 si+1,li+1=2li+1,ri+1=2ri−1s_{i+1},l_{i+1}=2l_i+1,r_{i+1}=2r_i-1si+1​,li+1​=2li​+1,ri+1​=2ri​−1。

对于在 li+1l_{i+1}li+1​ 和 ri+1r_{i+1}ri+1​ 之间的元素，分别由 lil_ili​ 和 rir_iri​ 与集合内部其它元素相加即可全部遍历。

由高中数学可知 li=2i−1,ri=(n−1)2i−1+1l_i=2^i-1,r_i=(n-1)2^{i-1}+1li​=2i−1,ri​=(n−1)2i−1+1，推导过程比较简单，这里就不给出了。

令 sizisiz_isizi​ 表示集合 sis_isi​ 的大小，Tu=∑i=1usiziT_u=\sum_{i=1}^u siz_iTu​=∑i=1u​sizi​。

同样的，可得 sizi=(n−3)2i−1+3,Tu=3u+(n−3)(2u−1)siz_i=(n-3)2^{i-1}+3,T_u=3u+(n-3)(2^u-1)sizi​=(n−3)2i−1+3,Tu​=3u+(n−3)(2u−1)。

那么我们就可以通过二分或者倍增的方式来确定第 kkk 个数在哪个集合，假设在第 www 个集合内。

那么 ans=lw+(k−Tw−1)ans=l_w+(k-T_{w-1})ans=lw​+(k−Tw−1​)。

如果不考虑高精运算带来的复杂度变化，单次询问时间复杂度为 O(log⁡2k)O(\log_2k)O(log2​k)。

注意事项

如果你在考试的时候没有注意到官方pdf上还写了 n=3n=3n=3 时，k≤105k\le 10^5k≤105，那么你需要注意到以下事情

考虑到 kkk 非常大，在 n=3n=3n=3 时可能达到极限 10100010^{1000}101000，python 也难以承受，但是 n=3n=3n=3 时 TuT_uTu​ 中的指数项就没了，我们就可以直接进行计算，不需要二分。

并且注意要对 n=1,n=2n=1,n=2n=1,n=2 的情况特判。

代码

这里放一个我写的无法通过的 c++ 实现版本。

int n;
int sum(int x)
{
    return 3 * x + (n - 3) * ((1 << x) - 1);
}
int main()
{
    // freopen("data.in", "r", stdin);
    // freopen("test.out", "w", stdout);
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int k, l, r, mid, w;
    while (cin >> n)
    {
        cin >> k;
        if (n == 1)
        {
            if (k > 1)
                cout << "-1\n";
            else
                cout << "1\n";
            continue;
        }
        if (n == 2)
        {
            if (k > 3)
                cout << "-1\n";
            else
                cout << k << "\n";
            continue;
        }
        l = 1;
        r = 10000;//本地测试用，故取了一个小数值
        w = 10001;
        while (l <= r)
        {
            mid = (l + r) >> 1;
            if (sum(mid) >= k)
            {
                w = mid;
                r = mid - 1;
            }
            else
                l = mid + 1;
        }
        cout << ((1 << w) - 1) + k - sum(w - 1) - 1 << "\n";
    }
    return 0;
}
