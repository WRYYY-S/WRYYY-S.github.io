记一次问题解决（ComfyUI-Desktop）

笔者刚开始捣鼓 AI 绘图，准备再找个模型试试，结果出锅了。

关掉 ComfyUI Desktop 之后，重新打开准备尝尝 Anima 的咸淡，报出了以下的错误：

Error invoking remote method 'run-action': Error: spawn UNKNOWN

当时我就懵了，我除了将新模型导入 checkpoint 文件夹之外，没有更改其它配置，唯一有可能的故障原因就是昨晚的更新。

但是昨晚更新之后，包括今日中午我都使用过了 Comfy，所以当时处于一个原因不明的状态。

之后就是正常的上网搜索，可能是我比较菜，也可能是真的就是没有，总之网上关联到 ComfyUI 出错的网页中列出的问题没一个是我遇到的（为什么我总会遇到一些不常见问题？）

最后，在 AI 的时代，使用 AI 工具出问题，当然是用 AI 来解决问题了！

在我的追问下，最后给出了是安全软件阻止 python 在非 AppData 区域启动子进程的回答，我寻思我没装杀软，但看到 Windows Defender 我就明白了。

在某次不记得时间关机后我执行了对 win 的更新，可能是这次更新导致安全配置升级，新增了智能应用控制的安全选项，不知为什么是默认打开的。

而我没有到 win 的应用商店下载的习惯，导致 7z 和 ComfyUI Desktop 均无法正常打开，不出所料的话，我那些没试过的软件，比如 PotPlayer 有可能也会被拦截。

关掉之后终于好了。

win 什么时候搞这么安全了。
