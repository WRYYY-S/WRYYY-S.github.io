上大学了，你需要了解什么？

发表于 2026-07-02 更新于 2026-07-23

同学向，本文将分成多个 part 向大家介绍我个人积累的一些对大学生活有用的东西，文中一般只会给下载困难的软件或文件附上下载链接。 我默认读者已经拥有电脑，如果你想要一些能在手机上用的相关软件但文中没提到可以再来找我。

Part 1 各类工具

基础的工具像是 WPS 或者 office 全家桶我就不提了，相信大家都会用。

The 1st\text{The 1st}The 1st Potplayer/VLC

播放器软件，前者更为集成，应该只能部署在 win 上，后者更为轻量，全平台通用。 大学生活如果单纯用 Windows 或者 MacOS 自带的播放器估计是完全不够，一是视频格式繁多，系统自带软件可能需要安装额外插件才可以播放，二是系统自带软件功能不能说没有，但实在太少了。

如果是 win 用户，可以无脑选 Potplayer，不建议在中文官网下（如果你不介意可能的突如其来的百度/夸克网盘诈骗），可以直接找资源，或者从下方链接下载（蓝奏云免登录下载），密码：fim2。

PotPlayer https://wryyy233.lanzouq.com/ihYxo3txf50b

如果你是别的平台，或者只是单纯想试试，可以下载 VLC，官网直接下载即可，这里就不挂链接了。

The 2nd\text{The 2nd}The 2nd Obsidian/Typora

markdown 编辑器，或者说笔记软件，本文就是用 Obsidian 写的。

markdown 和 LaTeX\LaTeXLATE​X 后面会有介绍，这里先不提。

Obsidian 的功能更多，也可以装扩展，但是包体比较大，不过这不是问题。

Typora 更简洁，导出 PDF 的字体更好看一些，可惜要付费，有一个老版本是免费的，大家可以自己找找。

这两个软件在大学要写论文或者技术性文章的时候会有用，看个人需求，我认为还是很有用的。

如果有会用 VS Code 的人也可以下载 markdown 扩展以编辑。

The 3rd\text{The 3rd}The 3rd 7-zip

简称 7z，目前最有用且最好用的解压缩软件没有之一，可以自动识别压缩包类型，改过后缀也问题不大，而且体积小，干净，解压缩能力强大，没有冗余功能，PC 平台通用，免费。比某些国内公司旗下的解压软件好上不知道多少，比微软官方的也好用不少。官网下载即可。

The 4th\text{The 4th}The 4th Transmisson/qBittorent/aria2

磁链下载工具，我之前应该已经写过很多遍了，考虑到这个对大多数人来说不能算是必须品，但总会有感兴趣的人，所以不感兴趣可以直接跳过。

磁链下载作为一个已经没落的下载方式（至少在国内绝对是），在某些地方还是特别有用的。（这里先不说）

分别介绍一下吧。

  • Transmisson，PC 平台通用，体积小，功能简单，配置容易，建议新手使用。下载链接：https://wryyy233.lanzouq.com/it3SW1eqdhkh
  • qBittorent，全平台通用（除国区 iOS），体积稍大，功能多，基础配置容易，扩展性高。密码：cobb 下载链接：https://wryyy233.lanzouq.com/iiojT3u1vxsh。
  • aria2，PC 平台通用，本体为命令行下载工具，直链磁链均可下载，不建议新手使用，经过配置可拥有图形化界面，功能强大，可以与某些网站联动使用，配置复杂，github 下载。

个人建议可以直接从 qBittorent 开始用，我也不想说什么要懂得分享的大道理了，配置问题可以私聊，我随机解答。

Part 2 各类网站

估计有些电脑使用基础的人会听过里面大部分的网站，但是我身边似乎不多的样子。

The 1st\text{The 1st}The 1st GitHub.com

知名开源代码社区，除托管代码之外有很多魔改用法，比如用于搭建博客，建立论坛（类似）。

你既可以在上面云端存储你的代码或文件，也可以下载别人开放的代码或文件，像上文提到的 qBit，aria2 和 7z 都有托管在 GitHub。当然还有很多好东西也可以在 GitHub 上下载，这里暂且不提。

因为 GitHub 的服务器架设在国外，所以在国内的访问性不稳定是正常的，有条件的可以自己买个梯子，当然，没条件的我们也可以使用一些镜像网站。

GitHub 加速下载代理 1：https://gh-proxy.com/

GitHub 加速下载代理 2：https://ghproxy.homeboyc.cn/

顾名思义，这两个网站是适用于加速下载的，也是上面的原因，有时候是可以访问但是下载速度是真的慢，所以一般在 release 界面获取到下载链接就可以使用代理加速下载。

本来还有一些镜像站，但是好像最近都挂了，这里就不再列出。

The 2nd\text{The 2nd}The 2nd note.ms

开放式云剪贴板，可以方便的转移需要的文字，但考虑到这是开放式的云剪贴版，不建议长时间保存，更不建议将域名后的路径泄露，否则会被别人删除或篡改。

但又因为这是开放的，所以这一定程度上可以用作网络聊天室。

The 3rd\text{The 3rd}The 3rd imgchr.com

图床，对于想要在网上用图片但没有云端存储方式，无法转为直链访问的人，网络图床是必备的。建议多找几个，别把鸡蛋放在同一个篮子里，没准哪天这个图床就撑不住挂了。

The 4th\text{The 4th}The 4th 蓝奏云

小体积文件网盘，小于 100M 的文件可以免费上传，并且免费免登录分享，上文提供了下载链接的用的就是蓝奏云，速度可观。

The 5th\text{The 5th}The 5th latexlive.com

在线 LaTeX\LaTeXLATE​X 编辑网站，所见即所得，可以用于 LaTeX\LaTeXLATE​X 的练习以及查找如何写某个样式。至于 LaTeX\LaTeXLATE​X，你们以后会用到的（大概率）。

The 6th\text{The 6th}The 6th yandex.com

国内给会搜索的人留的最后一扇窗，用过的都说好。
